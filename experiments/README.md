# Experiments

This directory keeps completed baseline work separate from the proposed
Focus-GhostNet experiments.

```text
experiments/
|-- baseline_study/      # Existing teacher, Focus-RCNet, and Lite0 experiments
`-- focus_ghostnet/      # Proposed lightweight student experiments
```

Use `baseline_study/` as the reference when comparing the proposed model with
earlier results. Put new Focus-GhostNet training scripts and downloaded outputs
under `focus_ghostnet/`.
