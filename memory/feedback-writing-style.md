When drafting text Hamza will send as himself (emails to dosen/penguji, messages), avoid patterns that read as obviously AI-generated:
- **No em dashes ("—")** for parenthetical asides. Use commas, periods, or restructure the sentence instead.
- **No bold headers / bullet-point templates** inside email bodies (e.g. "**1. Poin A**" followed by bullets). Write as plain flowing paragraphs, like a normal student email to a lecturer.
- General bar: the draft should read like something Hamza would plausibly type himself, not a structured corporate-style document.

**Why:** he flagged two drafts in a row ("kek ai generated gt dong", "jangan pake — lah, ai banget") for exactly these two things.

**How to apply:** any time drafting a message/email FOR Hamza to send (not internal notes to Claude), write plain conversational Indonesian paragraphs, no dashes, no markdown structure. This is distinct from technical/analysis responses to Hamza himself, which can still use structure/bold when useful.
